## Deployment

### Deploy

- Pull the latest code
- Pull the latest Docker images
- Start/restart the containers

### Seed Database

- Run the database seed script manually

Both workflows use `workflow_dispatch`, so you can run them from **GitHub Actions → Run workflow**.
